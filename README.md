# 🗃️ SQL Business Intelligence Analysis
> 🌐 **Full portfolio:** [nishmapm43.github.io](https://nishmapm43.github.io)
## Business Problem
A retail company needed answers to 10 key business questions 
from their sales database — without any BI tool. Pure SQL.

## Dataset
Fictional retail sales database with tables for orders, 
customers, products, and regions.

## Queries Written
10 business queries covering:
- Top 5 customers by revenue
- Monthly sales trend using window functions
- Products with declining sales quarter-on-quarter  
- Region-wise profit margin ranking
- Customer cohort — first purchase month analysis

## Key Techniques Used
- Window functions: ROW_NUMBER(), RANK(), SUM() OVER()
- CTEs (WITH clause) for multi-step logic
- GROUP BY + aggregate functions
- Subqueries and JOIN combinations
- CASE WHEN for conditional segmentation

## Tools Used
SQL (SQLite / MySQL compatible)

## Files
- `business_queries.sql` — All 10 annotated queries with comments
